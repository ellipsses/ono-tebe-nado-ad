# Оно тебе надо

Учебный проект Яндекс Практикума: вёрстка страницы аукциона вещей, в которые никто не верил.

Выполнила Полина Подлозная, ТРПО24-4.
Репозиторий проекта: https://github.com/ellipsses/ono-tebe-nado-ad

## Что сделано

- семантическая структура страницы: шапка, обложка, секция «Лоты», секция «Об аукционе», подвал;
- шрифт Raleway, подключённый локально;
- сетки на grid (шапка, секция «Об аукционе», подвал) и flex (меню, карточки лотов);
- общий класс `overlay` для затемнения обложки и карточек;
- классы названы по методологии БЭМ.

## Структура

- `index.html` — разметка страницы;
- `styles/global.css` — глобальные стили;
- `styles/style.css` — стили страницы;
- `fonts/` — шрифты;
- `images/` — изображения.

## Как посмотреть

Откройте `index.html` в браузере. Макет рассчитан на экраны ноутбуков (ширина страницы 1100px).
